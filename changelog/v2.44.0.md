# [2.44.0] - 2026-10-20

- **Permintaan user**: auto logout bila tidak ada aktivitas selama 5 menit (default), lama idle bisa diatur di menu parameter.
- **Setting**: `px_app_settings` key `session_idle_timeout_minutes` (default **5**, bilangan bulat 1-120; divalidasi di `NUMERIC_SETTINGS`). Diatur Admin di **Admin Parameters -> Manage Users -> Session security** ("Auto sign-out after [N] minutes of inactivity"). Nilai efektif dikirim ke setiap user lewat `idle_timeout_minutes` di respons login, `GET /api/auth/me` dan change-password. Cache 30 detik per proses (PUT mengosongkan cache proses itu).
- **Penegakan di server**: kolom baru `px_sessions.last_activity_at` (ALTER idempoten; baris lama NULL dibaca sebagai `created_at`). Hanya **login** dan endpoint baru **`POST /api/auth/activity`** yang memperbarui aktivitas - request biasa (GET, polling latar belakang, upload) tidak. Bila `now - last_activity_at` > batas: sesi dihapus, cookie dibersihkan, audit **`LOGOUT_IDLE`** (sekali, aktor = user itu; ditandai tes untuk akun tes), jawaban `401 { error: 'Session expired after inactivity', reason: 'IDLE_TIMEOUT', code: 'AUTH_REQUIRED', idle_timeout_minutes }`. Batas absolut 8 jam tetap. Rute publik (health, login, directorates, check-in, feedback) tidak terpengaruh. Logout menerima `{ reason: 'IDLE_TIMEOUT' }` (dicatat `LOGOUT_IDLE`). `PUT /api/admin/settings/:key` kini mengaudit `SETTINGS_CHANGE` untuk setiap key.
- **Browser** (`src/components/IdleSessionGuard.jsx` baru, dipasang `App.jsx` selama login): aktivitas = mousemove/mousedown/keydown/scroll/touchstart/wheel/tab kembali terlihat; ping `/api/auth/activity` maksimal tiap 30 detik; dialog peringatan 60 detik sebelum keluar (separuh batas bila lebih pendek) dengan hitung mundur dan tombol **Stay signed in**; saat habis -> logout dan halaman login menampilkan "You were signed out after N minutes of inactivity." Setiap 401 `IDLE_TIMEOUT` ditangani sama. Antar-tab lewat `localStorage` (`px_last_activity`, `px_idle_signout`): aktivitas di satu tab menjaga tab lain, sign-out idle di satu tab menyebar. Sign out manual tidak disiarkan (tab lain keluar pada request berikutnya). `apiClient.js`: event `px:unauthorized` membawa `detail { reason, idle_timeout_minutes }`.
- **Tes**: suite kini menjaga sesinya hidup (`realFetch` mengirim `/api/auth/activity` maksimal tiap 60 detik per cookie).
