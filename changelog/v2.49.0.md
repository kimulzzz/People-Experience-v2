# [2.49.0] - 2026-10-20

### 🔐 Akses Menu per User & Urutan Menu Baru (Added / Changed)

- **Permintaan user (2026-10-20)**: urutan menu Dashboard & Trends - Explore Metrics - Exit Interview - Action Library - Signature Program Events - About; Signature Program Events hanya untuk Admin dan user "HR Strategy", dengan setting akses menu per user di menu parameter. Ini butir (4) dari permintaan v2.48.0. Keputusan: checklist menu per user, tanpa role baru.
- **Kondisi sebelumnya**: Signature Program Events bisa dibaca semua login (non-pengelola tanpa kode akses, identitas peserta disamarkan, absensi/feedback dibatasi cakupan); hak kelola diberikan per direktorat lewat setting `event_manager_directorates` (default Human Resources), jadi tidak bisa dibatasi ke orang tertentu. Semua menu lain selalu tampil untuk semua login.
- **Akses menu (Added)**: 6 key `dashboard`, `explore`, `exit_interview`, `action_library`, `events`, `about`. Default USER (juga USER yang sudah ada): semua aktif kecuali `events`. ADMIN selalu semua menu (mengirim `false` apa pun untuk ADMIN -> 400; semua `true` diterima dan diabaikan). Disimpan di kolom baru `px_users.menu_access NVARCHAR(400) NULL` (JSON; NULL = default; ALTER idempoten) / field `menu_access` di `server/data/auth.json`. Aturan bersama: `server/db/menuAccess.js` (dipakai `sqlStorage.js`, `jsonStorage.js`, `authService.js`) dan `src/utils/menuAccess.js` (UI).
- **Penegakan server**: menu `events` -> semua API Signature Program Events (daftar lengkap di `docs/04` "Catatan v2.49.0"), termasuk yang baru digate: `GET /api/questions/master`, `GET /api/qrcode` dan static `/uploads/*` (dulu cukup login); `exit_interview` -> semua `/api/exit-interview/*` (endpoint selain `summary` tetap Admin saja); `action_library` -> `GET /api/action-library`. Ditolak -> 403 `{ error, code: 'MENU_ACCESS_DENIED', menu }`. Tetap publik: `GET /api/events/by-code/:code`, `POST /api/events/:id/attendance`, `POST /api/events/:id/feedback`. `dashboard`, `explore`, `about` hanya disembunyikan di UI: `calculate`/`trends`/`detail`/`by-directorate`/`alerts` tetap menjawab user login dalam cakupannya (`/api/alerts` tidak digate karena dipakai Dashboard). Akun dibaca ulang dari database setiap request, jadi perubahan Admin berlaku pada request berikutnya tanpa login ulang.
- **Hak event (Changed)**: USER dengan `events` = pengelola event lama (lihat + kelola: buat/hapus event, pertanyaan, hapus absensi/feedback, media, transkrip, ringkasan AI, PPT). Tanpa `events` -> tidak ada akses event sama sekali (403, termasuk baca). Tampilan baca-saja tersamar untuk USER lain (`eventRowsForViewer`, `hideEventCodes` di `server.js`) dihapus: USER dengan akses events melihat data event lengkap, termasuk identitas peserta dan kode akses check-in/feedback. `permissions.can_manage_events` = akses menu `events`. Setting `event_manager_directorates` tetap ada di `px_app_settings` tetapi tidak memberi hak apa pun lagi.
- **API (Changed)**: setiap objek user (login, `/api/auth/me`, `GET /api/admin/users`, respons create/update) memuat `menu_access` (map lengkap 6 key; Admin semua `true`). `POST /api/admin/users` dan `PUT /api/admin/users/:id` menerima `menu_access` parsial (key yang tidak dikirim tetap, `null` = kembali ke default); key tak dikenal atau nilai bukan boolean -> 400, tidak ada yang tersimpan. Audit: `USER_UPDATE` + `USER_MENU_ACCESS_CHANGE` (mis. `<username>: events:off->on`); `USER_CREATE` mencantumkan menu USER; ditandai tes bila akun tes terlibat (aturan v2.43.0).
- **Upgrade (sekali)**: pada boot yang menambah kolom `menu_access`, `migrateEventManagerMenuAccess()` memberi `events: true` kepada USER yang masih NULL dan cakupannya memuat direktorat di `event_manager_directorates`, supaya pengelola event lama tidak kehilangan akses; pilihan eksplisit tidak pernah ditimpa, aman diulang. Database utama: 0 akun dimigrasikan (hanya ada akun `admin`). JSON: sekali saat `auth.json` dimuat, untuk akun tanpa field `menu_access`.
- **UI (Changed)**: Header hanya menampilkan menu yang diizinkan, dengan urutan baru Dashboard & Trends, Explore Metrics (PX Metrics), Exit Interview, Action Library & AI Alerts, Signature Program Events, About. `App.jsx` hanya merender tab yang diizinkan dan jatuh ke menu pertama yang diizinkan; tanpa menu sama sekali -> "Your account has no menu access yet. Contact an Admin.". Disembunyikan bila menu terkait mati: tombol Dashboard "Simulate & Edit Metrics" (`explore`) dan "Manage Signature Programs" (`events`), klik kartu journey ke Explore Metrics (`explore`), tombol Header "N Deficits" (`action_library`), "Open Exit Interview Dashboard" di detail metrik exit survey (`exit_interview`), "Back to Dashboard" di tab Action Library (`dashboard`). Data event dan Action Library tidak di-fetch tanpa menunya. Admin Parameters -> Manage Users: form tambah/ubah mendapat checklist **Menu Access** (hanya role User; untuk Admin teks "Admin always has every menu") dengan peringatan bahwa Signature Program Events memberi hak event penuh; daftar user menampilkan "Menus: all" / "Menus: all except ..." / "Menus: none".
- **Tes**: Modul 51 baru (7 tes, `docs/07` §38). Modul 34, 35 dan 49 disesuaikan; Modul 38 (media) disesuaikan dan dijalankan terpisah oleh main session.
