### 📊 PX Index per Direktorat, Bobot PX Index Bisa Diatur & Metrik Non-Karyawan Bernilai Bankwide di Filter Direktorat (Added / Changed)

- **Permintaan user (2026-10-20)**: (1) PX Index per direktorat dalam dropdown di bawah panel PX Index, dibatasi cakupan user, klik = filter global; nilai direktorat = metrik direktorat + metrik yang hanya ada bankwide; (2) istilah tab About urut abjad per kategori; (3) metrik di kartu journey diurutkan Critical -> Warning -> On Target, di dalam status skor tertinggi dulu (pilihan user), No Data/Exempted paling bawah - hanya Dashboard; (5) bagian Journeys di atas Score Deficit Alerts, grafik tren lebih besar dengan sumbu Y dinamis dari nilai terendah/tertinggi periode terpilih; (6) bobot 70/30 bisa diubah di Admin Parameters. Butir (4) (urutan menu + akses menu per user) dikerjakan sebagai slice terpisah (rencana v2.49.0).
- **Aturan metrik non-karyawan di filter direktorat (Changed)**: sebelumnya filter direktorat Admin menonaktifkan metrik #1-#5 (`is_disabled`, keluar dari indeks) dan User melihatnya sebagai nilai bankwide read-only tetapi `excluded_from_index`. Kini di bawah filter direktorat/divisi/cakupan User apa pun (Admin dan User sama), setiap metrik `is_employee_metric === false` (#1-#5) dibaca pada **nilai bankwide** (respons bankwide / baris ESS Bankwide / snapshot OUTCOME) dan ikut dihitung di Survey Index, Outcome Index, journey, checkpoint dan alert. PX(direktorat) = bobot Survey x rerata berbobot metrik SURVEY berdata (metrik karyawan direktorat + metrik non-karyawan pada nilai bankwide) + bobot Outcome x rerata berbobot metrik OUTCOME (snapshot bankwide). Aturan `NO_DATA` tidak berubah. Payload: `is_disabled`/`excluded_from_index` tetap ada tetapi selalu `false` (`disabled_reason` `null`, `disabled_metrics_count` 0); baru `metrics[].is_bankwide_value` dan `bankwide_value_metrics_count`. `getMetricDetail()` mereset filter ke bankwide untuk metrik non-karyawan (`is_bankwide_value: true`); override khusus User di route `/api/metrics/:id/detail` dihapus. Opsi `bankwideReadOnly` dihapus dari `calculatePEIndex()`, `alertEngine.js` dan route. Alert: `is_bankwide_readonly` kini dari `is_bankwide_value`, komentar verbatim metrik itu diambil bankwide.
