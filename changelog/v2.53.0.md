# [2.53.0] - 2026-10-21

### 🧹 Fitur integrasi token (v2.52.0) dihapus seluruhnya (Changed / Removed)

- **Permintaan user**: menu **Integrations** di Admin Parameters tidak diperlukan - aplikasi on-premise tanpa internet. Keputusan: seluruh fitur integrasi v2.52.0 dihapus, bukan hanya menunya.
- **Dihapus**: `POST /api/integrations/social-media` (ingest dengan Bearer token) dan entri `PUBLIC_ROUTES`-nya (`authService.js`); `GET`/`POST /api/admin/integration-tokens`, `POST /api/admin/integration-tokens/:id/revoke`, `DELETE /api/admin/integration-tokens/:id`; tab **Integrations** (`IntegrationTokensManager.jsx` dihapus, `AdminParametersModal.jsx`); method storage token (`getIntegrationTokens`, `getIntegrationTokenByHash`, `createIntegrationToken`, dst.) di kedua backend; validasi JSON ingest dan rate limiter ingest (`socialMediaService.js`). Label sumber "Integration" di riwayat `SocialMediaUploadModal.jsx` ikut dihapus.
- **URL lama kini**: ingest -> **401** tanpa login (juga dengan header `Authorization: Bearer`), **404** dengan sesi Admin/USER; `/api/admin/integration-tokens*` -> **404** Admin, **403** USER, **401** tanpa login. Tidak ada yang tersimpan.
- **Database**: `px_integration_tokens` (0 baris) dihapus lewat `DROP` terjaga dan idempoten `dropRetiredIntegrationTokens()` (`sqlStorage.js`) saat boot (setelah `applySchema()`) dan di `migrate.js`; bila tabel ternyata berisi baris, tabel **dibiarkan** dengan peringatan di log. Tabel dihapus dari `schema.sql` -> jumlah tabel **36** (dihitung dari `CREATE TABLE` di `schema.sql`). Backend JSON: daftar `integrationTokens` yang kosong dihapus dari `server/data/auth.json` saat dimuat; yang berisi dibiarkan dengan peringatan.
- **Tidak diubah**: upload Excel metrik 1 (template, upload, riwayat, file asli, tabel detail, seed, tombol Template/Upload) - kini satu-satunya jalur data social media. `CHECK` constraint `source` di `px_social_media_stats`/`px_social_media_uploads` masih mengizinkan `'INTEGRATION'` (tanpa migrasi), tetapi tidak ada lagi yang menghasilkannya. Baris audit lama `INTEGRATION_TOKEN_*`/`SOCIAL_MEDIA_INGEST` (semua dari run tes) dibiarkan sebagai riwayat.
- **Tes**: Modul 55: 5 tes integrasi dihapus, 3 baru (URL lama hilang; `DROP` terjaga - tabel berisi tetap ada, kosong dihapus, lalu ABSENT; pembersihan `auth.json`) -> 15 tes. Suite penuh SQL (`TEST_SKIP_MODULES=8,24,27,32,38,41,42,43`): **327/327 lulus, 0 gagal, 16 tes dilewati**; ukuran suite 415 - 5 + 3 = **413**. Suite JSON penuh tidak dijalankan.
