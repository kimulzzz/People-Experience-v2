# [2.60.2] - 2026-10-28

### 🌐 Port default di satu tempat dan domain ngrok diizinkan (Changed)

- **Permintaan user**: tetapkan port default aplikasi, karena frontend nantinya akan dihubungkan ke ngrok.
- **Kondisi sebelumnya**:
  - Port sebenarnya sudah tetap: frontend 3000 (`strictPort`) dan backend 5000. Tetapi angka 3000 tertulis di `vite.config.mjs` dan di dua script `package.json` (`--port 3000`), dan target proxy `http://localhost:5000` ditulis mati, terpisah dari `PORT` yang dibaca backend.
  - Vite (sejak v6) menolak setiap host name selain localhost/IP ("Blocked request. This host is not allowed"), sehingga akses lewat `https://<nama>.ngrok-free.app` pasti gagal.
- **Perubahan** (`vite.config.mjs`, `package.json`):
  - Port default di satu tempat: `DEFAULT_FRONTEND_PORT` 3000 dan `DEFAULT_BACKEND_PORT` 5000. Keduanya bisa diganti lewat `.env`: `FRONTEND_PORT` (baru, opsional) dan `PORT` (variabel yang sama dengan yang dibaca `server/server.js`). Target proxy `/api`, `/uploads`, `/exports` kini ikut `PORT`, jadi frontend dan backend tidak bisa lagi menunjuk port yang berbeda.
  - Bila `FRONTEND_PORT` sama dengan `PORT`, Vite berhenti dengan pesan jelas (dulu proxy akan menunjuk dirinya sendiri).
  - `server.allowedHosts` dan `preview.allowedHosts` mengizinkan domain ngrok: `.ngrok-free.app`, `.ngrok-free.dev`, `.ngrok.app`, `.ngrok.dev`, `.ngrok.io`. Host tambahan (mis. domain tetap) lewat `ALLOWED_HOSTS=host1,.domain2` di `.env`. Host lain tetap ditolak.
  - `npm run dev` / `npm run client` kini cukup `vite`; host `0.0.0.0` dan port dibaca dari `vite.config.mjs`. `npm run preview` memakai port dan proxy yang sama.
- **Cara pakai ngrok**: jalankan aplikasi (`npm run dev`), lalu `ngrok http 3000`. Hanya port frontend yang di-tunnel; backend (5000) tetap internal dan dicapai lewat proxy Vite. Jangan memakai `--host-header=rewrite`: backend membandingkan Origin browser dengan Host (pertahanan CSRF), dan login akan ditolak bila Host diubah.
- **Catatan penting**:
  - ngrok adalah layanan cloud: semua lalu lintas (termasuk login dan data karyawan) melewati server ngrok. Ini bertentangan dengan aturan **100% on-premise** proyek ini, jadi pakai hanya untuk demo/uji dan sebaiknya dengan data dummy.
  - Lewat proxy, semua pengguna ngrok terlihat oleh backend sebagai `127.0.0.1`, sehingga batas percobaan login per IP (rate limit di memori) berlaku bersama untuk semua pengguna ngrok. `TRUST_PROXY=1` di `.env` membuat backend membaca IP asli dari header `X-Forwarded-For` ngrok, tetapi header itu bisa dipalsukan oleh klien lokal yang tidak lewat ngrok; tidak diubah di versi ini.
  - Cookie sesi tidak diberi flag `Secure` karena Vite → backend memakai http; cookie tetap terkirim di https ngrok.
- **Tidak berubah**: backend, API, database, dan `.claude/launch.json` (tetap `PORT=5000`, port 3000). `/api/health` `version` = `2.60.2`.
- **Tes**: `vite build` lulus; setelah restart, `localhost:3000` dan proxy `/api/health` jalan; permintaan dengan header `Host: <nama>.ngrok-free.app` diterima, host asing (mis. `evil.example.com`) tetap 403. Suite regresi penuh (SQL, backend kedua :5002): **444/444 lulus**, 16 tes di-skip; modul 8, 24, 27, 32, 38, 41, 42, 43 di-skip karena kode event dan media tidak tersentuh. 5 batch unggahan sisa tes (8 baris) dihapus setelahnya.
