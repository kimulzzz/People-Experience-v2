### 📱 Metrik 1: Data Social Media (Instagram, LinkedIn, TikTok) lewat Upload Excel & Token Integrasi (Added / Changed / Fixed)

- **Permintaan user (2026-10-21)**: metrik 1 "Career website & social media follower, reach & engagement growth" tidak punya dimensi direktorat (hanya bankwide), dan tab **Internal Transaction Records**-nya harus berisi data *Social Media Engagement Rate* dari Instagram, LinkedIn dan TikTok (followers, reach, engagement). Data masuk lewat upload Excel atau injeksi otomatis dari sistem lain. Keputusan user: skor metrik 1 tetap **manual** (`raw_value` yang diisi Admin) untuk sekarang, mungkin dihitung kemudian; kolom lengkap.
- **Masalah lama (Fixed)**: tab itu menampilkan 5 baris SLA rekrutmen per direktorat/unit (seed `px_recruitment_sla_by_unit` metrik 1, sisa definisi lama "% SLA of candidate fulfillment") - data yang salah untuk metrik bankwide. Seed `initialOperationalRecords[1]` dihapus; setiap boot menghapus baris SLA **metrik 1 saja** (`removeMetric1SlaRows`, idempoten; JSON: saat `store.json` dimuat). Tabel drilldown metrik lain (3, 4, 14, 25) tidak disentuh.
- **Tabel baru** (jumlah tabel 34 -> **37**; rincian `docs/08` §25):
  - `px_social_media_stats`: satu baris per platform per bulan - `platform` (`CHECK` Instagram/LinkedIn/TikTok), `stat_year` (2000-2100), `stat_month` (1-12), `followers`/`reach`/`engagement` (`INT >= 0`), `source` (`UPLOAD`/`INTEGRATION`/`SEED`), `upload_id`; `UNIQUE (platform, stat_year, stat_month)` -> kirim ulang bulan yang sama = update (*upsert*).
  - `px_social_media_uploads`: riwayat batch (`source` UPLOAD/INTEGRATION, `file_name`, `uploaded_by`, `total_rows`/`inserted_rows`/`updated_rows`/`replaced_seed_rows`, `period_from`/`period_to`, `uploaded_at`).
  - `px_integration_tokens`: `name`, `token_hash` (SHA-256, unik), `token_hint`, `scope` (`CHECK` hanya `SOCIAL_MEDIA_INGEST`), `created_by`/`created_at`, `last_used_at`, `revoked_at`/`revoked_by`, `is_test`.
  - Backend JSON: `socialMediaStats` / `socialMediaUploads` di `store.json`; token di `server/data/auth.json` (`integrationTokens`), seperti akun login.
- **Upload Excel (Admin)**: `GET /api/admin/social-media/template` -> `Template_Social_Media_Metric_1.xlsx` (Platform | Year | Month | Followers | Reach | Engagement; satu baris per platform untuk bulan lengkap terakhir, angka kosong). `POST /api/admin/social-media/upload` (multipart `file`, hanya `.xlsx` dengan MIME Excel/zip, maks. 5 MB): divalidasi utuh - satu error = tidak ada yang disimpan, 400 `{ errors: [{ row_number, column, reason }] }`; `.csv`/`.xls`/MIME lain 415; terlalu besar 413. Diterima: alias platform (IG, Insta, Linked In, TT; tanpa membedakan huruf/spasi), bulan nama Inggris/Indonesia, singkatan atau 1-12, urutan kolom bebas (baris header = baris pertama dengan sel "Platform" di 10 baris pertama), pemisah ribuan "12,500". Ditolak: platform tak dikenal, tahun di luar 2000-2100, angka negatif/desimal/kosong/bukan angka, rumus tanpa nilai tersimpan, platform+bulan ganda dalam satu file. File asli disimpan di `server/data/social-uploads/<upload_id>.xlsx` (gitignored; unduh lewat `GET /api/admin/social-media/file/:upload_id`); riwayat `GET /api/admin/social-media/uploads`. Audit `SOCIAL_MEDIA_UPLOAD`.
- **Injeksi otomatis (Added; dihapus di v2.53.0, lihat [2.53.0])**: `POST /api/integrations/social-media` dengan `Authorization: Bearer <token>` (atau sesi Admin, untuk uji), body `{ "rows": [ { platform, year, month, followers, reach, engagement } ] }` (1-500 baris), validasi sama dengan upload (error: `row_number` = posisi di array, `column` = nama field). Tanpa/token salah/dicabut -> 401 + `WWW-Authenticate: Bearer`; sesi USER -> 403; maks. 30 request/menit per token atau sesi dan 20 token gagal/menit per IP -> 429 + `Retry-After`; Origin host lain -> 403 (pemeriksaan global). Audit `SOCIAL_MEDIA_INGEST` dengan user `integration:<nama token>`; batch tercatat sebagai "Integration: <nama token>". Contoh dan rincian: `docs/04` "Catatan v2.52.0".
- **Token integrasi (Added; dihapus di v2.53.0, lihat [2.53.0])**: Admin Parameters -> tab baru **Integrations** (`IntegrationTokensManager.jsx`). Token = `pxi_` + 64 karakter hex, **ditampilkan sekali** saat dibuat; server hanya menyimpan SHA-256 dan petunjuk 12 karakter pertama; hanya berlaku untuk endpoint ingest di atas; tidak pernah ditulis ke log. Endpoint: `GET`/`POST /api/admin/integration-tokens` (nama wajib, maks. 100 karakter, unik di antara token aktif -> 409), `POST /api/admin/integration-tokens/:id/revoke`, `DELETE /api/admin/integration-tokens/:id` (hanya token yang sudah dicabut; aktif -> 409). Audit `INTEGRATION_TOKEN_CREATE`/`REVOKE`/`DELETE`.
- **Dummy vs data asli**: seed fiktif Januari-September 2026 (27 baris, 3 platform x 9 bulan, `source = 'SEED'`).
