# [2.50.0] - 2026-10-20

### 📊 Pertanyaan ESS dari Manage Questions, Tipe Percentage, ESS Carry-Forward & Snapshot Pertanyaan (Added / Changed / Fixed)

- **Permintaan user (2026-10-20)**: (A) teks pertanyaan ESS di Spreadsheet View / Card View detail metrik berbeda dengan Manage Questions - harus sama, web dan template mengikuti Manage Questions; (B) tipe jawaban baru Percentage untuk ESS; (C) ESS hanya sekali setahun (November): tahun berjalan memakai nilai tahun lalu sampai hasil tahun berjalan diunggah; (D) Explore Metrics: hapus tombol Detail (survei) / View Data (outcome) dan label "FIXED"; (E, lanjutan) bila pertanyaan diubah, riwayat tetap menyimpan pertanyaan yang dipakai saat data dikirim, dan unduhan data mentah harus menangani template yang berubah. Keputusan user: kuartal dummy ESS 2026 dihapus; kolom file ESS dipetakan menurut posisi; semua pertanyaan ESS menjadi Percentage.
- **Penyebab (A)**: `buildEssDetail` (`calculationEngine.js`) menampilkan teks header file ESS sebagai teks pertanyaan dan hanya meminjam key/label pertanyaan terkonfigurasi bila teksnya sama setelah normalisasi; yang tidak sama tampil sebagai "Question N". Template ESS memakai teks Manage Questions, jadi web dan template bisa berbeda.
- **(A) Pertanyaan ESS = Manage Questions**: template ESS dan semua tampilan web memakai pertanyaan terkonfigurasi yang bisa diskor (bukan `FREE_TEXT`), urut tampilan (`configuredEssQuestions`). Kolom pertanyaan file dipetakan **menurut posisi** (G = pertanyaan 1, H = pertanyaan 2, ...); teks header file hanya disimpan sebagai `file_label`. Jumlah kolom pertanyaan = G s.d. kolom terakhir yang berisi nilai di baris data mana pun; bila tidak sama dengan jumlah pertanyaan terkonfigurasi -> **400**, tidak ada yang disimpan (mis. "The file has 3 question columns with values (G-I), but 2 questions are configured for this metric in Manage Questions. Column G must hold question 1, H question 2, and so on - download the current template."). Teks header yang berbeda bukan error. Error lama "Column X has a value but no question text in row 1" dihapus. Hasil lama dipetakan menurut posisi saat dibaca (tanpa migrasi). Respons upload ESS menambah `file_question_labels` (`question_labels` kini = teks terkonfigurasi). Tipe breakdown ESS `PERCENTAGE` (dulu `ESS_PERCENT`).
- **(B) Tipe pertanyaan Percentage**: setting `question_types` mendapat opsi `PERCENTAGE` "Percentage (0–100%)" (ditambahkan saat boot ke database yang sudah ada: `addMissingOptions` / `topUpAddedOptions`; label lain tidak diubah). Setiap boot mengubah pertanyaan metrik ESS yang belum `PERCENTAGE` menjadi `PERCENTAGE` (`enforceEssPercentageQuestions`; database utama: 38 baris pada boot pertama). `POST /api/admin/survey-questions/:metric_id` untuk metrik ESS selalu menyimpan `PERCENTAGE`; metrik ESS baru (SQL) mendapat pertanyaan `PERCENTAGE`; dropdown tipe di Manage Questions terkunci untuk ESS. Default kode 11 metrik ESS kini `PERCENTAGE` (dulu `SCALE_1_10`/`SCALE_1_5`). Metrik SYSTEM boleh memakai tipe ini: jawaban CSV 0-100 (akhiran `%` dan koma desimal diterima), di luar 0-100 atau bukan angka -> baris ditolak; template CSV memberi petunjuk `[<label>: Persentase 0-100]` dan contoh 92/88/85; detail menampilkan "xx.x%".
- **(C) ESS carry-forward**: nilai metrik ESS = hasil **terakhir** dengan tahun-bulan <= akhir periode yang dilihat (MTD: bulan itu; YTD: bulan akhir YTD yang dibatasi jam server), dari tahun mana pun (`essPeriodEndKey` + `selectEssResult`). Periode yang belum dimulai (bulan/tahun depan) -> `NO_DATA`. `period_window.basis = 'LATEST_RESULT'` untuk ESS; field baru `ess_carried_forward` (selain `ess_period`/`ess_period_label`). Detail menampilkan "ESS result November 2025 (latest available) - ESS runs once a year". **Menggantikan** aturan v2.37.0 "MTD ESS = hanya bulan template". Metrik SYSTEM tidak berubah. Batas pengingat ESS 25 November untuk 11 metrik (laporan developer: sudah benar di database utama, tidak diubah).
- **Seed**: kuartal dummy ESS 2026-03/06/09 (v2.37.0) tidak lagi di-seed (`ESS_SEED_DUMMY_PERIODS` diganti `ESS_REMOVED_DUMMY_PERIODS`). Boot menghapus **hanya** upload `seed-ess-<metric>-2026-03|06|09` ber-`uploaded_by` "Seed (dummy)" beserta barisnya (`cleanupRemovedEssDummySeed`, satu transaksi; JSON saat `store.json` dimuat). Database utama: 33 upload, 429 baris. Upload Admin periode apa pun tidak disentuh.
- **(D) Explore Metrics (`Calculator.jsx`)**: tombol **Detail** (survei) dan **View Data** (outcome), label **FIXED** di header kolom Actions & Evidence, dan chip legenda "Detail: Metric Drilldown" dihapus. Detail tetap dibuka dengan klik baris metrik. Tombol Template / Evidence / Upload tetap; tautan Evidence (juga di `MetricDetailModal.jsx`) memakai nama file dari server (bisa `.zip`).
- **(E) Snapshot pertanyaan**: setiap batch CSV SYSTEM dan upload ESS menyimpan set pertanyaan saat itu di kolom baru `px_survey_uploads.questions_snapshot_json` (JSON: field `questions_snapshot`), format `{ "<metric_id>": [{ key, label, text, type, order }] }`; baris hasil ESS menyimpan per pertanyaan `{ key, label, text, type, order, file_label, score }`. Data lama tidak di-backfill (`questions_snapshot` `null`). `GET /api/surveys/history` mengirim `questions_snapshot`.
- **(E) Tampilan**: detail selalu memakai teks Manage Questions terkini. Bila set yang tersimpan berbeda -> `questions_changed_since_upload: true`, per pertanyaan `original_texts` / `text_changed` (ESS juga `original_text`, `file_label`), `question_text_source` `SNAPSHOT` / `CURRENT_CONFIG` (detail ESS). UI: catatan amber "Questions changed since this result was uploaded." dan baris "At upload: ..." di bawah pertanyaan yang berubah (Spreadsheet View dan Card View). Template selalu memakai konfigurasi terkini.
- **(E) Evidence**: baris dikelompokkan per versi set pertanyaan (key, label, teks, tipe; `server/services/evidenceVersions.js` baru). Satu versi -> CSV tunggal seperti sebelumnya; lebih dari satu -> **ZIP** berisi satu CSV per versi (`<nama dasar>_v<n>_<dari>_to_<sampai>.csv`) + `README.txt` (sumber tiap versi: `SNAPSHOT`, `FILE_HEADER` untuk baris ESS lama, `CURRENT_CONFIG` untuk batch SYSTEM lama, plus daftar pertanyaan). Header CSV SYSTEM tetap `<key>_<label>` (perubahan teks hanya terlihat di README); header CSV ESS memuat teks pertanyaan. Export semua metrik (`metric_id=ALL`) tidak berubah. `generateSurveyEvidenceCsv` / `generateEssEvidenceCsv` diganti `generateSurveyEvidence` / `generateEssEvidence` (mengembalikan `{ kind: 'csv' | 'zip', ... }`).
