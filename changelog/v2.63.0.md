# [2.63.0] - 2026-11-24

### 🏅 Kategori PX Index menurut rentang skor (Added)

- **Permintaan user**: label kategori di sebelah skor PX Index di Dashboard, dengan setting di Admin Parameters.

  | Skor PX Index | Kategori (default) |
  | :--- | :--- |
  | >= 85 - 100 | Exceptional |
  | >= 75 - < 85 | Strong |
  | >= 65 - < 75 | Moderate |
  | >= 50 - < 65 | Needs Improvement |
  | < 50 | Critical |

- **Setting baru** `px_app_settings.px_index_categories` = `[{ label, min, color }]`, dari skor tertinggi. Yang disimpan hanya batas bawah, jadi tidak mungkin ada celah atau tumpang tindih: kategori berakhir tepat di bawah batas bawah kategori di atasnya, kategori terakhir selalu mulai dari 0. Ditambahkan saat boot bila belum ada; editan Admin tidak ditimpa. Aturan bersama: `server/db/pxCategories.js`.
- **Admin Parameters -> Journey Parameters -> PX Index Categories** (`PxCategoriesCard.jsx`): ubah label, batas bawah dan warna, tambah/hapus kategori (2-10). Disimpan lewat `PUT /api/admin/settings/px_index_categories` (Admin saja, audit `SETTINGS_CHANGE`); ditolak 400 bila batas tidak menurun, kategori terakhir tidak mulai dari 0, label kosong/kembar/> 40 karakter, batas di luar 0 - < 100 atau > 2 desimal, atau warna bukan `#RRGGBB`.
- **Dashboard**: label di sebelah "/ 100", mengikuti periode dan filter direktorat/cakupan yang sedang tampil; tooltip menampilkan rentangnya. Tanpa data (PX Index kosong) label tidak tampil.
- **API**: `GET /api/metrics/calculate` mendapat `px_category` `{ label, color, min, max, range_label }` atau `null`. Dinilai dari PX Index yang sudah dibulatkan 2 desimal (angka yang dilihat pengguna). Perubahan setting langsung berlaku tanpa restart.
- **Tidak berubah**: skor, status metrik (On Target / Warning / Critical), alert, panel PX per direktorat, grafik tren, PPT. Tidak ada tabel atau env baru.
- **Verifikasi**: Modul 71 (3 tes). Suite penuh SQL Server **479/479**, 17 skip (`TEST_SKIP_MODULES=8,24,27,32,38,41,42,43`). Ukuran suite 566 (SQL Server) / 567 (PostgreSQL). Browser pane: label "Exceptional" pada 90,12, ubah batas lewat UI (95 -> "Strong", dikembalikan ke 85), batas tidak valid menonaktifkan tombol Save, tampilan mobile 375 px. Suite JSON dan PostgreSQL tidak dijalankan; tanpa QC terpisah.
