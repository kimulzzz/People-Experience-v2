Boot mengisi `AVERAGE` untuk metrik 1 dan 3 sekali, hanya bila kolom masih `NULL`. Metrik `AVERAGE` memakai tata letak tahunan "baris bulan" (template user):
  - Parser (`outcomeValueService.js`): baris header = baris dengan nama bulan terbanyak di 10 baris pertama ("Score Asli" di atasnya diabaikan), tepat **satu** baris data; karakter U+200B/NBSP dibuang; "-", "n/a", kosong = tidak ada nilai; metrik %: teks `"3.87%"` atau `"3.87"` = 3,87%, sel angka = pecahan Excel x 100 (0.0349 -> 3,49%); > 100% ditolak; bulan setelah bulan berjalan yang berisi nilai ditolak; semua bulan "-" ditolak; satu error = seluruh file ditolak.
  - Upload: field form `year` (2000..tahun berjalan) wajib; upload tahun Y **mengganti semua bulan Y** yang tersimpan (tahun lain tetap). File asli tetap disimpan di `server/data/outcome-uploads/` seperti v2.54.0.
  - Template `GET /api/admin/outcome-values/:metric_id/template?year=` (default tahun berjalan): A1 judul metrik + tahun, B1:M1 "Score Asli" (merged), baris bulan Jan..Des berisi nilai tersimpan, target, pita tier.
  - Evidence CSV: baris per bulan + baris "Average" per tahun.
  - Skor: YTD = rata-rata bulan tersimpan di jendela (Jan..akhir jendela), MTD = bulan itu saja, tidak ada bulan = `NO_DATA`; hasil rata-rata lalu dinilai lewat tier (v2.54.1). Field baru `outcome_aggregation`, `outcome_months_count`, `outcome_average_label` (mis. "Average of 7 months (Mar-Sep 2026)"), `period_window.basis` `AVERAGE_OF_MONTHS`.
